# 🌾 Kisan Alert

**Empowering Farmers with Generative AI & Real-Time Weather Data**

![License](https://img.shields.io/badge/License-MIT-10B981?style=for-the-badge)
![Status](https://img.shields.io/badge/Status-Active-success?style=for-the-badge)

<br />

> Access to accurate, hyper-local weather data and expert agronomy advice is critical for agricultural success. **Kisan Alert** bridges this information gap by providing a premium, mobile-first interface. It combines real-time meteorology with **Google Gemini AI** to generate actionable, village-level farming advisories.

</div>

<br />

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| 🤖 **AI Agronomist** | A sleek chat interface powered by Gemini to answer complex farming queries instantly. |
| 📸 **AI Plant Doctor** | Computer vision integration—upload photos of diseased leaves for instant diagnosis and treatment plans. |
| 💬 **Automated SMS** | Fully functional Twilio backend integration to send critical advisories directly to basic mobile phones. |
| 📈 **Live Dashboard** | High-contrast Bento grid and interactive Chart.js graphs for moisture and weather tracking. |
| 🌐 **14 Languages** | Seamlessly switch between regional languages (Hindi, Bengali, Telugu, Marathi, Tamil, etc.). |
| 🗣️ **Text-to-Speech** | Accessibility feature that reads advisories out loud for users with low literacy. |

## 🏗️ Architecture Note

This project operates on a professional **split-repository model**:

* 🔓 **Frontend (Public):** 100% Open Source UI. You are welcome to view, learn from, and use this code.
* 🔒 **Backend API (Private):** The server logic, AI prompts, and Twilio routing are securely locked in a separate repository to protect API keys and server limits.
